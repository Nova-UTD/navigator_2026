# lidar_cluster

**Status:** not started. **Full spec: [#20](https://github.com/Nova-UTD/navigator_2026/issues/20).** Read it before you start.

Groups nearby LiDAR points into objects and fits a 3D box around each, published on `/perception/lidar/objects`. Doesn't know what each object is; the class comes from the camera later.
