# voxel_3d

**Status:** not started. **Full spec: [#12](https://github.com/Nova-UTD/navigator_2026/issues/12).** Read it before you start.

Thins the LiDAR into 10 cm cubes (one point per occupied cube) and publishes it on `/perception/lidar/voxels` for `lidar_cluster` and `static_obstacle_grid`.
