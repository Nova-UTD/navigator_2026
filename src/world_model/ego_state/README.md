# ego_state

**Status:** not started. **Full spec: [#9](https://github.com/Nova-UTD/navigator_2026/issues/9).** Read it before you start.

Publishes our own position, heading, speed, acceleration and turn rate in one message on `/world/ego`, which every node downstream reads. Doesn't use the map.
