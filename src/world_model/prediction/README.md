# prediction

**Status:** not started. **Full spec: [#24](https://github.com/Nova-UTD/navigator_2026/issues/24).** Read it before you start.

Adds a 5-second predicted path to every tracked object (cars follow their lane, people keep walking) and publishes them on `/world/objects`. Simple physics, not machine learning.
