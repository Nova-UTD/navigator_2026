# trajectory_follower

**Status:** not started. **Full spec: [#30](https://github.com/Nova-UTD/navigator_2026/issues/30).** Read it before you start.

Drives the car along the planned trajectory: pure-pursuit steering and a speed PID, 50 times a second, on `/control/command`. Ported from the old cruise controller.
